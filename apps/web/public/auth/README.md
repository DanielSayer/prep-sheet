# Sign-in brand assets

- `google-g.png` is Google's multicolour G from the [Sign in with Google branding guidelines](https://developers.google.com/identity/branding-guidelines).
- `discord-mark.svg` is the blue symbol shown in [Discord's brand assets](https://discord.com/branding). The mark is used unchanged.
- `google-sans-medium.ttf` is Google Sans Medium from [Google Fonts](https://fonts.google.com/specimen/Google+Sans). Its licence is in `google-sans-OFL.txt`.
