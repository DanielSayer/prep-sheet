# Prep Sheet branding, recipe and knife v1

Generated with the built-in image_gen tool, based on the approved first concept. Prompts are saved in prompts.json. Original generated PNGs are retained as masters; export.ps1 creates standard-size raster exports and the ICO container.

Palette follows apps/web/src/styles/base.css: cream #faf7ef, forest ink #283e32, leaf green #527b42, orange #ee8a4b. Generated lettering approximates the rounded Nunito character of the app; it is raster artwork, not an exact typeset Nunito wordmark. Generated colour values have slight variation.

## Files

- logo-horizontal.png: transparent horizontal wordmark, 2172 x 724.
- share-1200x630.png: wide link-preview card.
- share-1080x1080.png: square social card.
- favicon.ico: 16, 32 and 48 pixel PNG frames.
- favicon-16.png, favicon-32.png, favicon-48.png: individual browser icons.
- apple-touch-icon.png: 180 x 180.
- icon-192.png and icon-512.png: app icons.
- icon-master.png: transparent simplified symbol, 1254 x 1254.
- share-wide-master.png and share-square-master.png: original generated social artwork.
- preview.html: local visual overview with favicon previews at native size.

Icon exports and square social export use opaque cream backgrounds. This maintains contrast when displayed against dark browser chrome. The 16px version is necessarily less detailed than larger icons.

These assets are saved for review. Application components, favicon links, manifests and Open Graph metadata have not been changed. The social copy is a proposed tagline: Your recipes, ready to cook.
